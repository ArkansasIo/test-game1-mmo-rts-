# Glossary

| Term | Definition |
|---|---|
| Action | A server-side mutation intent such as `technology`, `train`, `combat`, or `colonize_planet`. |
| Anomaly | A generated or persistent universe event with risk, discovery, and reward behavior. |
| Ascension | A late-game progression transition that grants a validated permanent or semi-permanent reward. |
| Commander | The authenticated player identity controlling colonies, fleets, technologies, and social membership. |
| Colony | A commander-owned settlement on a universe planet. |
| Cooldown | A server-side time restriction preventing repeated or overlapping operations. |
| DefCon | A military readiness or protection level that affects command state and combat eligibility. |
| Deuterium | The ninth resource, primarily used as fuel and for advanced strategic systems. |
| Discovery | A persistent record that a commander has scanned, explored, or learned about generated content. |
| Event | An auditable record of a player-visible or competitive state transition. |
| Fleet | A group of ships, units, weapons, and mission metadata moving through the universe. |
| Galaxy | A universe subdivision containing sectors. |
| Government | A political profile that modifies administration, command, diplomacy, and production. |
| Mothership | A persistent mobile command platform with hull, modules, hangars, science, and exploration ability. |
| NPC civilization | A persistent non-player political and military actor in the shared universe. |
| Page contract | Metadata describing a route’s purpose, controls, actions, tables, formulas, permissions, and states. |
| Player technology | A commander’s technology level linked to a technology catalogue entry. |
| Prerequisite | A required technology, progression level, resource, or state needed before an action is allowed. |
| Procedural universe | A repeatable universe generated from stable coordinate seeds and layered with persistent player state. |
| Queue | A scheduled construction, research, training, repair, production, travel, or mission record. |
| RBAC | Role-based access control used in addition to authentication and ownership. |
| Research queue | A queue of technology upgrades with cost, level transition, completion time, and status. |
| Sector | A universe subdivision containing solar systems and strategic map data. |
| Service layer | Authoritative PHP domain logic that validates, calculates, persists, and audits gameplay state. |
| State payload | Server-generated page data serialized for safe client rendering. |
| Tier | One of 21 progression bands containing 23 levels. |
| Turn | A settlement cycle that processes production, upkeep, queues, missions, and events. |
| Universe | The highest procedural hierarchy level and shared game world container. |
| Vault | Protected Naquadah storage separate from the available balance. |
