## Implemented gameplay systems

The project includes the eight-resource economy of Metal, Crystal, Naquadah, Energy, Dark Matter, Food, Water, and Population. Population capacity, life-support consumption, morale, workforce assignment, production, queues, and settlement are represented through the player-resource and colony services.

Progression is represented as a **21-tier by 23-level** system with level effects, tier mastery, ascension requirements, rewards, and progression-state persistence. Combat includes target selection, attack and raid previews, deterministic force comparison, protection checks, cooldowns, casualties, loot, battle persistence, reports, and event logging. Covert operations include reconnaissance, spying, sabotage, detection scoring, bounded damage, probability caps, agent expenditure, cooldowns, and classified reports.

The universe and colony systems include galaxy, sector, solar-system, planet, moon, coordinate, exploration, colonization, biome, planet-bonus, planet-defense, mothership, and jump-gate mechanics. Markets include resources, weapons, and mercenaries with ownership, balance, price, fee, expiry, and transaction safeguards. Social systems include rankings, alliances, messages, blacklists, reports, and read-state transitions.

## Server authority contract

> The browser submits player intent only. The PHP service layer is authoritative for authentication, CSRF, RBAC, ownership, protection, cooldown, resource, population, queue, and transaction validation.

Mutating actions are dispatched through `actions/game.php` and delegated to the service layer. Database writes use transactions and roll back on exceptions. Successful mutations write a `game_events` record where the module contract requires an audit event, then return refreshed state through the dashboard flow.
