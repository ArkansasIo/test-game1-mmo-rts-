02 / SYSTEM ARCHITECTURE
The codebase is organized around clear boundaries
FRONTEND
Authenticated shell · nested navigation · page registry · master and module CSSBrowser submits intent; it never decides authoritative outcomes.
APPLICATION
PHP routes · CSRF · RBAC · secure action dispatch · flash feedbackOne controlled path connects forms to state-changing operations.
DOMAIN
Formula engines · combat · covert · world services · repositoriesTransactions, row locks, validation, and configurable rules keep systems consistent.
DATA / OPS
54-table MySQL schema · seeds · cron turns · audit events · smoke testsThe database is the source of truth and the worker keeps time moving.
Modular boundaries make the game easier to test, balance, and extend.
